# Changelog

## v1.0.0 - 2026-10-13

- Consolidates the decision workflow into one product, one skill key, one repository, and one installation.
- Adds Quick, Standard, and Full session modes.
- Adds three formal rounds: independent positions, forced debate, and final rescoring.
- Adds per-option scores, confidence, visible score movement, and relevance weighting.
- Adds anti-groupthink steelmanning when early consensus appears.
- Adds credible legal, security, cash-flow, reputation, operational, and boundary risk vetoes.
- Adds a preserved minority report.
- Adds the decision contract: validation test, go threshold, kill criterion, owner, deadline, and review date.
- Adds portable evaluation cases under `references/evals.json`.
- Retains the five original lenses, interview-first CRIT intake, portability, and non-affiliation safeguards.
- Establishes this repository as the single source of truth; Marketing Council and BVD Decision Room are no longer separate product names.

## v0.2.1 - 2026-07-28

- Updates OpenClaw compatibility status from experimental to supported after current OpenClaw behavior testing.
- Clarifies that OpenClaw should be treated on equal footing with Claude, Codex, and Hermes for supported skill use.
- Improves onboarding for regular Claude users with a no-terminal Project setup path.
- Adds regular ChatGPT onboarding with Project, Custom GPT, and normal-chat copy/paste options.
- Adds a copy/paste install prompt for users who want ChatGPT Codex, Claude Code, Codex, Hermes, OpenClaw, or another agent to install the skill for them.
- Keeps terminal install commands for Codex and Hermes.

## v0.2.0 - 2026-07-24

- Initial public repository package.
- Includes `SKILL.md` version `0.2.0`.
- Adds README, example output, compatibility checklist, visual assets, license, contribution notes, and security/privacy guidance.
- Platform status at launch packaging:
  - Claude: supported
  - Codex: supported
  - Hermes: supported
  - OpenClaw: experimental at launch packaging; updated to supported in v0.2.1
